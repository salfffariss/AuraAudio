# AuraAudio v2.0.1: Forensic Engine Hardening & Native AIFF Decoding

> **Release Type:** GitHub Pre-release (`v2.0.1`)

AuraAudio v2.0.1 is a targeted accuracy and reliability update on top of v2.0.0. It resolves four concrete forensic-analysis and decoder issues uncovered during an audit of `NyquistSpectrumAnalyzer.cs` and independent testing against the public 8-file CC0 SoniqTools audio test suite, synchronizes the methodology documentation with the shipping code, and adds automated regression coverage.

## What Changed

- **Native AIFF Decoder (`Audio/AudioDecoderFactory.cs`):** Uncompressed `.aiff` and `.aif` files now decode directly through `NAudio.Wave.AiffFileReader` instead of Windows Media Foundation, eliminating `MediaFoundationException` errors during playback and inspection. Compressed AIFC variants still fall back to `MediaFoundationReader`.
- **Quiet CD Upsample Detection (`NyquistSpectrumAnalyzer.cs`):** Widened the CD spectral cliff window from `21.5 - 22.7 kHz` to `21.0 - 22.7 kHz`, added a dead digital ultrasonic silence detector (`<= -152 dBFS` above `22.5 kHz` on `>= 48 kHz` containers), and guarded `isSmoothAcousticRollOff` against steep CD transition slopes (`<= -36 dB/oct`). Quiet 24-bit / 96 kHz tracks upsampled from 44.1 kHz CD masters are now flagged as `UpscaledFromCd` instead of `AcousticNaturalRollOff`.
- **Soft Acoustic MP3-in-FLAC Detection:** Added `ComputeDeadZeroLossyBrickwall`, scanning `15.0 - 19.5 kHz` for brickwall drops (`>= 20 dB`, steepness `<= -60 dB/oct`) collapsing into dead digital silence (`<= -152 dBFS`). This catches 128 kbps MP3 transcodes even on gentle solo-piano material that rolls off below `-48 dB` before `16 kHz`.
- **Genuine Soft Acoustic 16-bit / 44.1 kHz Recognition:** Updated `isSmoothAcousticRollOff` harmonic reach to `max(upperEnvelopeReachHz, detectedKneeHz) >= 9,000 Hz`, preventing genuine soft 16/44.1 acoustic recordings with natural TPDF dither floors from falling into `Inconclusive`.
- **Band-Averaged Lookups, Hardened Alignment & Broadband Mirror Guard:**
  - Replaced all remaining single-bin FFT lookups (`16k`, `20k`, `35k`, `40k`) with linear-power band averages (`GetBandPowerDb`).
  - Tightened `hasSmoothHiResContinuation` and added `isFlatBroadbandMirror` so broadband non-ideal resampler artifacts are routed to `Inconclusive` instead of `VerifiedLossless`.
  - Expanded `Detect24In32Alignment` from `100` frames (~1 ms) to `4,096` frames (~42 ms at 96 kHz) with active-frame sign-extension checks so quiet track onsets do not trigger false zero-padding flags.
  - Tracked seek failures explicitly: non-seekable streams report `00:00 (0.0%)` with a transparent note rather than an invented seek timestamp.
- **Evidence-Based Verdict Wording & Documentation Sync:**
  - Updated Indonesian (`NyquistSpectrumAnalyzer.cs`) and English (`AudioIntegrityReport.cs`) verdict descriptions to evidence-based phrasing, added the moderate-evidence hedge (`drop < 10 dB`) on `UpscaledFromCd`, and applied the high-bitrate AAC/Opus spectral limitation note consistently across every `VerifiedLossless`, `AcousticNaturalRollOff`, and `HybridMaster` verdict.
  - Rewrote [docs/METODE_ANALISIS_KEASLIAN_AUDIO.md](../METODE_ANALISIS_KEASLIAN_AUDIO.md) so every formula, named constant, decision table, and limitation (including the `-6.02 dB` Hann coherent-gain scale offset and synthetic DSD placeholder curve) matches the `v2.0.1` code.

## Requirements & Installation

- **OS:** Windows 10 (build 19041+) or Windows 11, **64-bit (`win-x64`)**.
- **Runtime:** Self-contained single-file package, no separate .NET installation required.
- **Install:** Download `AuraAudio-v2.0.1-win-x64-standalone.zip`, extract it to any folder, and run `AuraAudio.exe`.

## Upgrade Notes

- Drop-in replacement for v2.0.0 with no database schema changes.
- Users upgrading directly from v1.x should back up `aura_library.db` first; AuraAudio applies the additive `play_history` table migration automatically on startup.

## Known Limitations

- **Spectral Limits on High-Bitrate AAC/Opus:** Modern AAC (`>= 192 kbps`) and Opus (`>= 128 kbps`) encoders can preserve energy up to `20 - 24 kHz` without a brickwall lowpass filter and cannot be distinguished from lossless masters by magnitude FFT alone.
- **1-Bit DSD Analysis:** DSD (`.dsf`) files are not decimated to PCM inside the inspector, so they return `Inconclusive` with a clearly labeled representative curve (`IsSyntheticSpectrum = true`).
- **Mixed EN/ID UI Labels When Default Indonesian Is Active:** `App.xaml` defaults to `Strings.id.xaml`, so top-bar route names and legacy status strings appear in Indonesian while most v2.x XAML headings appear in English until English is selected under `Settings > General`.
- **Non-Virtualized Detail Views at Extreme Scale:** Primary library lists (`Songs`, `Albums`, `Artists` master list, `Queue`, `History`, `Lyrics`, sidebar playlists, and `Add to Playlist`) use `Recycling` virtualization, whereas `AlbumDetailView`, `PlaylistDetailView`, `ArtistDetailView`, `PlaylistsOverviewView`, and `SearchView` render inside outer `ScrollViewer`s.
