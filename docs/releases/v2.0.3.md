# AuraAudio v2.0.3: Windows Setup Wizard, LocalAppData Storage & Automated CI Releases

> **Release Type:** Packaging & Stability Update (`v2.0.3`)

AuraAudio v2.0.3 introduces an official **Windows Setup Wizard (`AuraAudio-v2.0.3-Setup-win-x64.exe`)** alongside the portable ZIP package, moves all user-writable runtime files (`library.db`, thumbnail cache, and diagnostic logs) strictly under `%LocalAppData%\AuraAudio\` so the install directory stays read-only safe, and adds automated Windows CI release builds.

---

## Added

- **Windows Setup Wizard (`installer/AuraAudio.iss`):** Inno Setup 6 installer (`AuraAudio-v2.0.3-Setup-win-x64.exe`) with:
  - **Per-User install by default** (`%LocalAppData%\Programs\AuraAudio`, no Admin/UAC prompt) and optional **All Users** install (`C:\Program Files\AuraAudio`).
  - Automatic **Start Menu** shortcut, optional **Desktop** shortcut, **Settings > Apps > Installed apps** registration with official uninstaller, and `Win+R` → `auraaudio` (`App Paths`).
  - Automatic clean upgrade in place (closes running AuraAudio cleanly, replaces binaries, preserves `library.db` and playlists).
- **Unified Release Packager (`tools/release/build_release.ps1`):** Uses one fixed staging directory (`artifacts\publish\staging`) cleaned automatically after packaging, audits the exact 2-file single-file output (`AuraAudio.exe` + `AuraAudio.pdb`), and produces both the Setup EXE and Portable ZIP with `.sha256` sidecars.
- **Automated GitHub Actions Release Pipeline (`.github/workflows/release.yml`):** Tag-triggered `windows-latest` workflow that verifies `<Version>` match, builds with `-warnaserror`, runs headless Release unit tests, compiles `Setup.exe` + `standalone.zip` + `.sha256`, and publishes them to GitHub Releases.
- **Centralized User-Writable Paths (`Core/AppDataPaths.cs`):** Single source of truth for `%LocalAppData%\AuraAudio\library.db`, `Cache\Thumbnails\`, and `Logs\` (`aura_crash.log`, `aura_startup_error.log`), with `AURA_DATA_DIR` override support and automated regression coverage (`tests/AuraAudio.Tests/AppDataPathsTests.cs`).

## Changed & Fixed

- **Read-Only Install Directory Safety (`DatabaseManager.cs`, `ThumbnailCacheManager.cs`, `CoverArtLoader.cs`, `App.xaml.cs`, `MainViewModel.cs`):** Moved disk thumbnail caching and crash/startup logs out of the executable directory into `%LocalAppData%\AuraAudio\`, enabling clean operation when installed under `C:\Program Files\AuraAudio`.
- **Headless Software Audio Sink Fallback (`Audio/Controller/AudiophilePlaybackController.cs`):** Non-WASAPI software/null output engines now initialize cleanly with a virtual silent `AudioDevice` on machines without physical audio endpoints (such as Windows Server CI runners).
- **Dynamic UIA Smoke Test (`tests/ui/smoke_ui.ps1`):** Reads target version directly from `AuraAudio.csproj` and verifies `InstallDirClean=True` (zero `Cache/` or `.log` files created in the executable directory).

---

## Requirements & Installation

- **OS:** Windows 10 (build 19041+) or Windows 11, **64-bit (`win-x64`)**. No separate .NET runtime installation is required.
- **Option 1 — Windows Setup Wizard (Recommended):**
  1. Download `AuraAudio-v2.0.3-Setup-win-x64.exe` below and run it. *(If Windows SmartScreen appears, select **More info → Run anyway**.)*
  2. Choose **Install for me only** (no UAC) or **Install for all users** and complete the wizard.
- **Option 2 — Portable Standalone ZIP:**
  1. Download `AuraAudio-v2.0.3-win-x64-standalone.zip`, extract it anywhere, and run `AuraAudio.exe`.
- **Checksums:** SHA-256 verification sidecars (`AuraAudio-v2.0.3-Setup-win-x64.exe.sha256` and `AuraAudio-v2.0.3-win-x64-standalone.zip.sha256`) are attached directly to this release.
