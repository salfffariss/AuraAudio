# AuraAudio v2.0.0: Pure Monochrome Redesign

> **Release Type:** GitHub Pre-release (`v2.0.0`)

AuraAudio v2.0.0 is a full desktop UI rebuild for Windows 10 and 11. Twenty-eight of thirty-one XAML files (90.3%) were written from scratch around a strict pure-monochrome visual system (`R = G = B` on every UI surface, control, border, selection highlight, focus ring, and context menu), a redesigned multi-surface shell, synchronized lyrics playback, persistent play history, a unified Settings screen, and an in-app monochrome Nyquist FFT spectrogram.

## Highlights

- **Redesigned Multi-Surface Shell**
  - **48px Top Bar** with navigation rail toggle, Back/Forward history, route title, global search pill with live autocomplete hints (`Ctrl+F`), and monochrome window caption controls.
  - **Collapsible Left Rail (`248px <-> 56px`)** organizing Home, Library views, a collapsible virtualized Playlists list with drag-and-drop targets, Audio Inspector, and Settings.
  - **Floating Bottom Dock Capsule (`72px`)** housing playback transport, recessed Now Playing LCD with live audio format badge (`SignalPathFlyout`), direct-scrub timeline, smooth volume control (with muted indicator), Info (`Ctrl+I`), Lyrics (`Ctrl+Shift+L`), Queue (`Ctrl+U`), Mini-Player (`Ctrl+Shift+M`), and Full-Screen (`Ctrl+Shift+F`).
  - **Responsive Dual-Purpose Right Split Pane (`360px`)** switching between **Playing Next** (drag-to-reorder), **History** (with reset), and **Lyrics** — docked inline on wide windows (`>= 1440 DIPs`) and sliding as an overlay on narrower windows.
- **Rebuilt Library & Discovery Views**
  - **Home:** Editorial shelves built strictly from your local SQLite library (*Recently Added*, *Jump Back In*, *Hi-Res & Lossless Masters*, and *Your Artists*).
  - **Songs:** Virtualized `DataGrid` with right-click column customization and a collapsible 3-column **Column Browser** (*Format*, *Artist*, *Album*).
  - **Albums:** Frameless 1:1 artwork grid powered by a single-pass `VirtualizingUniformGrid` (`3`–`6` responsive columns) with hover play/context actions, quick filter, and 5 sort modes.
  - **Artists:** `280px` virtualized master index paired with a live discography pane, plus dedicated **Album Detail** and **Artist Detail** pages with sticky compact headers.
  - **Dedicated Search:** Top-bar autocomplete popup plus a full Search page with 5 scope filter pills (*All*, *Songs*, *Albums*, *Artists*, *Playlists*) and local library format/Hi-Res browse cards.
- **Full-Screen Stage & Always-On-Top Mini-Player**
  - **Full-Screen Player (`Ctrl+Shift+F`):** Centered 5-column playback stage that morphs into a split Artwork + Lyrics layout when synced or plain lyrics are available.
  - **Mini-Player (`Ctrl+Shift+M`):** Standalone topmost window switching between Compact (`350x160`) and Album View (`350x350`) with an expandable Queue/Lyrics tray.
- **Synchronized Lyrics & Persistent Play History**
  - Reads sidecar `.lrc` files, embedded LRC timestamps, ID3v2 `SYLT` frames, and plain-text fallback tags, plus in-app `.lrc` import from both the Lyrics pane and the `Get Info` sheet.
  - Synced mode highlights the active line with click-to-seek, smooth auto-scroll (pausing during manual scroll), and 3-dot instrumental gap indicators.
  - Play events are stored locally in SQLite (`play_history`, capped at 500 entries) powering *Home > Jump Back In* and *Queue > History*.
- **Monochrome Audio Inspector & Unified Settings**
  - Full-page **Audio Inspector** and tabbed **Get Info (`Ctrl+I`)** sheet (*Details*, *Audio & Path*, *Authenticity*, *Lyrics*) featuring a pure-monochrome Nyquist FFT spectrum plot (distinguishing reference curves via stroke weight, luminance, and dash patterns instead of color heatmaps).
  - Unified **Settings (`Ctrl+,`)** with breadcrumb navigation across *General*, *Playback & DAC*, *Library & Files*, *Accessibility*, and *About*.
- **Pure-Monochrome Palette, Contrast & Motion**
  - Every UI color token is defined in `UI/Tokens/NeutralTokens.xaml` with `R = G = B`, paired with app-scope `SystemColors` overrides so Windows accent colors do not bleed into text selections, focus rings, or context menus.
  - All 39 active contrast pairs pass WCAG 2.1 (`>= 4.5:1` for text, `>= 3.0:1` for interactive borders/controls).
  - Display-synced critically damped spring transitions (`SpringAnimator`, zero per-frame allocations) with full Reduced Motion support (`SystemParameters.ClientAreaAnimation` and in-app toggle).
  - **Volume & App Icon Fixes:** Digital volume scaling now operates smoothly (click-free 5 ms ramp, bit-exact passthrough at 100%, DoP-safe) across both WASAPI Exclusive and Shared modes, and the application icon is updated to a pure-monochrome spectrum glyph.

## What Is Unchanged

- Core **WASAPI Exclusive / Shared** playback architecture, gapless sample-exact stitching, anti-pop micro-fade, and DSD (DoP / DSD-to-PCM) decoding pipeline.
- Local **SQLite library scanner** and metadata indexer.
- **Nyquist FFT & LSB entropy authenticity analysis algorithm** (4096-bin multi-window FFT, spectral slope OLS regression, dither shelf detection, and 24-bit LSB entropy audit).

## Requirements & Installation

- **OS:** Windows 10 (build 19041+) or Windows 11, **64-bit (`win-x64`)**.
- **Runtime:** Self-contained single-file package — **no separate .NET installation required**.
- **Install:** Download `AuraAudio-v2.0.0-win-x64-standalone.zip`, extract it to a folder of your choice, and run `AuraAudio.exe`.

## Upgrade Notes

- **Database Migration:** On first launch, v2.0.0 runs an additive `CREATE TABLE IF NOT EXISTS play_history` migration and enables SQLite foreign-key enforcement (`ForeignKeys = true`). Existing `tracks`, `albums`, `artists`, `playlists`, `playback_session`, and `app_settings` tables remain intact.
- **Recommendation:** Back up your existing `aura_library.db` file before upgrading from v1.x.

## Known Limitations

- **Mixed EN/ID UI Labels When Default Indonesian Is Active:** `App.xaml` still loads `Strings.id.xaml` by default, so top-bar route names and legacy status strings appear in Indonesian while most new v2.0.0 XAML headings are English until English is selected under `Settings > General`.
- **Non-Virtualized Detail / Secondary Lists at Extreme Scale:** Primary library surfaces (`Songs`, `Albums`, `Artists` master list, `Queue`, `History`, `Lyrics`, sidebar playlists, and `Add to Playlist`) use `Recycling` virtualization, whereas `AlbumDetailView`, `PlaylistDetailView`, `ArtistDetailView`, `PlaylistsOverviewView`, and `SearchView` render inside outer `ScrollViewer`s without virtualization.
- **Hardware & Display Verification Scope:** Automated runtime pixel checks used WPF `RenderTargetBitmap` (desktop `CopyFromScreen` was unavailable in the non-interactive build session), and automated motion invariants ran under deterministic 60 Hz / 165 Hz clocks rather than an unoccluded foreground display. Live physical USB DAC WASAPI Exclusive ear-checks and 150% DPI visual checks were not part of the automated gate run.
