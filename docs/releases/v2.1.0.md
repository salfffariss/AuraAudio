# AuraAudio v2.1.0: Cardless 165 Hz Synced Lyrics & Immersive Artwork Backdrop

> **Release Type:** Minor Feature Release (`v2.1.0`)

AuraAudio v2.1.0 introduces a **cardless, zero-layout synced lyrics experience** across the Full-Screen player, the 360 px Right Pane, and the Mini-Player tray, paired with a subtle **artwork-derived animated backdrop** for the Full-Screen player and Mini-Player. All text, icons, buttons, borders, progress bars, scrollbars, and all other screens remain strictly pure monochrome (`R = G = B`).

---

## Highlights

### 1. Cardless Synced Lyrics & Progress-Filled Interlude Indicator
- **Borderless Typography (`UI/Views/LyricsView.xaml`, `UI/Controls/SyncedLyricsViewport.cs`):** Removed the opaque card container, hairline box border, scrollbar, and permanent header bar from synced lyrics in Full-Screen Split, the 360 px Right Pane, and the Mini-Player Lyrics Tray. Plain unsynced lyrics keep their scrollable reading layout, and a quiet `Import .lrc` action reveals on hover or keyboard focus in the writers footer (`Aura.Lyrics.FooterImport`).
- **Distance Falloff Without Reflow:** Keeps `FontFamily` (`Font.Display`), `FontWeight` (`Bold`), and `FontSize` / `LineHeight` (`28/37 px` Full-Screen, `19/26 px` Compact) fixed across all states, driving active-line emphasis purely with GPU-composited `Opacity` (`1.00 / 0.56 / 0.46 / 0.40`) and left-anchored `ScaleTransform` (`1.00 / 0.93 / 0.90 / 0.88`) springs (`response = 0.26 s`, critically damped). The active line locks to a fixed vertical anchor (`32%` Full-Screen, `30%` Compact) with smooth per-row edge fade, click-to-seek, 4 s manual-scroll pause/auto-resume, and full keyboard navigation (`Tab`, `Up`, `Down`, `Home`, `End`, `Enter`, `Space`).
- **3-Dot Progress Interlude Indicator:** Instrumental breaks and leading intros `>= 5.0 s` display three left-aligned dots interpolated smoothly on the display clock (`0.42 -> 1.00` opacity left-to-right across the gap duration) and fade out cleanly when inactive.

### 2. Zero-Layout Lyric Scrolling Smoothness
- **Root-Cause Fixes:** Phase 1 diagnostics traced choppy lyric motion to re-entrant `ScrollViewer.ScrollToVerticalOffset` calls inside `CompositionTarget.Rendering` without `RenderingTime` deduplication (producing 84%-91% duplicate callbacks per vsync, `7,404-13,211` layout passes, and `450-820 MB` GC churn in `3.6 s`) plus instantaneous `FontSize/LineHeight/FontWeight` reflow ahead of `DispatcherPriority.Loaded` scrolling.
- **Measured Before vs After (123 synced lines, `165 Hz`, `vsync = 6.06 ms`, `1.5x = 9.09 ms`, `3.0x = 18.18 ms`, deterministic probes):**

| :--- | :---: | :---: | :---: | :---: | :---: |
| **Full-Screen Split** (+ animating backdrop in v2.1.0) | `0.18 / 0.37 / 0.58 ms` | **`0.0050 / 0.0108 / 0.0254 ms`** (`0` >1.5x / `0` >3x) | `120` -> **`0`** | `52,372 B` -> **`480.8 B`** | `1.43 ms` -> **`1.0918 ms`** (`0` >1.5x) |

- **Allocation & Deduplication Note:** Zero user objects are allocated per frame in steady-state animation loops; the `96.7 B/f` (lyrics) and `360.0 B/f` (backdrop) figures reflect .NET 24-byte `double` boxing inside WPF `DependencyObject.SetValue`. `SpringAnimator` now deduplicates `CompositionTarget.Rendering` by `RenderingEventArgs.RenderingTime` (`3,118 -> 0` duplicate callbacks in real-time Full-Screen).
- **Measurement Transparency:** The frame-time numbers above come from deterministic `165 Hz` probes (`StepExternalClockForTest(1/165)` + `UpdateLayout()`), because Windows 11 DWM throttled WPF composition commits to ~5 Hz even on a blank 1-rectangle foreground window in the automated verification session (`DwmFlush` confirmed `165.2 Hz` panel vsync). Live 165 Hz visual motion was verified manually by the author.

### 3. Artwork-Derived Animated Backdrop (Full-Screen & Mini-Player)
- **Perceptual Palette & GPU-Friendly Soft Blobs (`ArtworkPaletteExtractor`, `ImmersiveBackdropControl`):** Extracts 4 OKLab/OKLCH color roles once per track on a background thread (`32x32` sample, ~`0.67 ms/track`, bounded 64-entry LRU cache by `CoverArtCacheKey`). Renders 3 five-stop Gaussian-approximated `RadialGradientBrush` blobs (2 in Mini-Player Compact; collapsed and frozen in Mini-Player Album View) with 650 ms A/B track cross-fades and slow `RenderTransform`-only Lissajous drift (`24-38 s` periods, zero `BlurEffect` or `DropShadowEffect`). Grayscale and missing covers automatically render a pure-neutral monochrome studio gradient (`R = G = B`).
- **Readability-First Conservative Tuning (`AppleMusicSpatial` Default):** The backdrop is intentionally conservative behind text, lyrics, and controls to guarantee WCAG 2.1 readability across bright white, pastel, highly saturated, dark, noisy, grayscale, and missing artwork. The default `AppleMusicSpatial` preset combines a post-sRGB linear luminance ceiling (`Y <= 0.220`) with a spatially varying pure-black scrim (lighter ambient glow around cover artwork, deeper protection behind the top bar, lyrics column, and lower controls). Verified on rendered pixels across all 10 test covers and 6 animation phases: worst-case `Tertiary #A0A0A0 = 4.76:1` (`>= 4.5:1`), `Lyric +-1 = 5.03:1` (`>= 4.5:1`), and unfilled interlude dots (`0.42` opacity) `>= 3.47:1` (`+0.47` margin over `3.0:1`). `SafeDefault` and `BalancedVivid` remain exposed as named presets in code.
- **Accessibility, Power & Performance Controls:**
  - New **Animated backdrop** toggle under `Settings > Accessibility` (`app_settings["animated_backdrop"]`, default ON).
  - Automatically falls back to a static gradient whenever playback is paused, the host window is minimized or hidden, Windows Reduced Motion or in-app Reduced Motion is active, Windows Battery Saver is active, or if rolling 2.0 s `p95` frame time exceeds `1.5x` vsync for two consecutive windows.
- **Strict Pure-Monochrome Isolation:** Verified at both token level (`check_color_purity.py --full`: `155` files scanned, `40` neutral tokens checked, `0` defects with an explicit 3-file backdrop allowlist) and rendered-pixel level (`0` chromatic pixels across `2.6+ million` non-artwork pixels rendered over a neutral backdrop replacement, `0` non-neutral rendered brushes outside `ImmersiveBackdropControl`, and `0` leaked chromatic pixels outside the backdrop layer).

## Upgrade Notes (From v2.0.3)

- **In-Place Upgrade:** `AuraAudio-v2.1.0-Setup-win-x64.exe` uses the exact same Inno Setup `AppId` (`{7B6D9A3F-4E21-4C8B-9F1A-3D8E6A2C5109}`) as `v2.0.3`, upgrading binaries in place while preserving your `%LocalAppData%\AuraAudio\library.db`, playlists, play history, and settings.
- **New Setting:** Adds `app_settings["animated_backdrop"]` to SQLite, defaulting to `"1"` (ON). Turn it off anytime in `Settings > Accessibility > Animated backdrop` to keep a static artwork gradient.

## Requirements & Installation

- **OS:** Windows 10 (build 19041+) or Windows 11, **64-bit (`win-x64`)**. No separate .NET runtime installation is required.
- **Option 1: Windows Setup Wizard (Recommended):**
  1. Download `AuraAudio-v2.1.0-Setup-win-x64.exe` and run it. *(If Windows SmartScreen appears, select **More info -> Run anyway**.)*
  2. Choose **Install for me only** (`%LocalAppData%\Programs\AuraAudio`, no UAC) or **Install for all users** (`C:\Program Files\AuraAudio`). Existing `v2.0.3` installations upgrade in place automatically.
- **Option 2: Portable Standalone ZIP:**
  1. Download `AuraAudio-v2.1.0-win-x64-standalone.zip`, extract it anywhere, and run `AuraAudio.exe`.
- **Checksums:** SHA-256 verification sidecars (`AuraAudio-v2.1.0-Setup-win-x64.exe.sha256` and `AuraAudio-v2.1.0-win-x64-standalone.zip.sha256`) are attached to this release.
