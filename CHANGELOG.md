# Changelog

All notable changes to AuraAudio are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.3] - Unreleased

### Added
- **Windows Setup Wizard (`installer/AuraAudio.iss`):** Added an Inno Setup 6 installer generating `AuraAudio-v<version>-Setup-win-x64.exe` with per-user install by default (`%LocalAppData%\Programs\AuraAudio`, no UAC) plus optional all-users install (`C:\Program Files\AuraAudio`), Start Menu and Desktop shortcuts, official Windows Installed Apps uninstaller, `App Paths` (`Win+R` → `auraaudio`), and in-place upgrade support preserving `library.db`.
- **Unified release packager & GitHub Actions workflow (`tools/release/build_release.ps1`, `.github/workflows/release.yml`):** Automated single-folder staging (`artifacts\publish\staging`, preventing folder buildup), publish-hygiene checks, portable ZIP + Setup EXE + `.sha256` generation, and tag-triggered GitHub Release publishing.
- **Centralized runtime storage paths (`Core/AppDataPaths.cs`, `tests/AuraAudio.Tests/AppDataPathsTests.cs`):** Unified SQLite database, thumbnail disk cache (`%LocalAppData%\AuraAudio\Cache\Thumbnails`), and crash/startup logs (`%LocalAppData%\AuraAudio\Logs`) with `AURA_DATA_DIR` override support and automated read-only install-directory verification.

### Changed
- **Read-only install-directory safety (`DatabaseManager.cs`, `ThumbnailCacheManager.cs`, `CoverArtLoader.cs`, `App.xaml.cs`, `MainViewModel.cs`):** Moved disk thumbnail cache and diagnostic logs out of the executable directory into `%LocalAppData%\AuraAudio\`, allowing AuraAudio to run cleanly from read-only folders such as `C:\Program Files\AuraAudio`.
- **Dynamic smoke-test version & install-dir checks (`tests/ui/smoke_ui.ps1`):** Reads target version directly from `AuraAudio.csproj` and asserts zero log or `Cache/` writes inside the executable directory.

## [2.0.2] - 2026-11-21

### Added
- **Pure-managed RFC 9639 FLAC decoder (`Audio/Flac/SafeFlacDecoder.cs`, `Audio/Flac/SafeFlacWaveStream.cs`):** Replaces `BunLabs.NAudio.Flac` with a zero-`unsafe` managed C# decoder derived from `SimpleFlac` / Project Nayuki (MIT License), featuring live CRC-8 frame-header and CRC-16 frame-footer verification, 64-bit LPC accumulators, `SEEKTABLE` + sparse frame-index sample-accurate seeking, ID3v2 prefix skipping, Rice escape code `0`, and bounded probing for unknown-length streams.
- **Hi-Res-to-Hi-Res upsampling verdict (`AuthenticityVerdict.UpscaledHiRes`):** Detects containers `>= 88.2 kHz` upsampled from lower standard rates (`48 / 88.2 / 96 / 176.4 / 192 kHz`, up to `85%` of container rate) when all four physical criteria hold (active passband, `>= 25 dB` drop and `<= -60 dB/oct` slope across source Nyquist, container-aware dead-silence upper band, and P90 multi-segment confirmation). Renders under `VerdictCategory = "Caution"` in both English and Indonesian.
- **Crash-isolated benchmark harness (`tools/benchmark/`):** Per-file child-process runner (`AuraAudio.BenchmarkWorker` + `run_benchmark.py` + frozen source-master DEV/HOLDOUT `split.json`) measuring decode stability, runtime, canonical RFC 9639 PCM MD5 integrity, and forensic verdicts.
- **Regression & UI purity coverage (`FlacDecoderSafetyTests.cs`, `ForensicV202RegressionTests.cs`, `RuntimePixelPurityTests.cs`, `VisualTreeClickSafetyTests.cs`, `InspectorTrackingTests.cs`, `AudioRenderStabilityTests.cs`, `LibraryScannerRescanTests.cs`):** Added synthetic FLAC safety, ID3v2, non-standard bit-depth, mid-stream CRC corruption, forensic v2.0.2, `UpscaledHiRes` monochrome Inspector/InfoSheet, `ContentElement` click-traversal, Inspector track-following, real-time audio render stability/soak, and rescan deletion pruning tests plus opt-in `AURA_BENCHMARK_CORPUS` gates.

### Changed
- **Strict FLAC conformance & decode performance:** The managed decoder enforces RFC 9639 CRC-8/16 and metadata validity checks rather than decoding corrupt streams into garbage PCM, rejects mid-stream format changes with `NotSupportedException`, and decodes `1.45x–2.26x` faster (`-31.0%` to `-55.8%`) than `v2.0.1` across five representative 16/24-bit music files (`44.1–192 kHz`).
- **Forensic wording, documentation & test hygiene:** Updated bilingual caveats, `README.md`, and `docs/METODE_ANALISIS_KEASLIAN_AUDIO.md` to state physical spectral limits honestly (high-bitrate AAC/Opus, MP3 V0, Vorbis q5, MP3 320 kbps near `20.1–20.2 kHz`, quiet solo-piano MP3, linear-interpolated pink noise, and window-position sensitivity). Replaced hardcoded local paths in `SyntheticCorpusTests.cs` with `AURA_REAL_CORPUS` / `AURA_LOCAL_MUSIC_DIR` environment variables. Preserved verbatim upstream `SimpleFlac` and Project Nayuki MIT notices in `THIRD_PARTY_NOTICES.md` and `SafeFlacDecoder.cs`.
- **Borderline verdict shifts vs `v2.0.1`:** On a 300-track real FLAC library sample, `275/300` (`91.7%`) kept identical verdicts and `25/300` (`8.3%`) changed (net `VerifiedLossless: 91 -> 94`, `AcousticNaturalRollOff: 93 -> 89`, `HybridMaster: 3 -> 1`, `Inconclusive: 66 -> 70`, `SuspectedUpscaledLossy: 1 -> 0`, `UpscaledFromCd: 41 -> 41`, `ZeroPadded24Bit: 5 -> 5`).
- **Version metadata:** Updated application version to `2.0.2` across `AuraAudio.csproj`, `MainWindow`, `MiniPlayerWindow`, `SettingsViewModel`, `RuntimePixelPurityTests`, and `tests/ui/smoke_ui.ps1`.

### Fixed
- **Uncatchable FLAC decoder crashes (`CRITICAL #1`):** Eliminated all `13` fatal `0xC0000005 System.AccessViolationException` crashes across the 263-file external FLAC corpus (`13 -> 0` fatal crashes; `0` timeouts) and reduced `ietf/faulty/09` (`blocksize 1`) from a `9.2 s` stall to `3 ms`.
- **Silent FLAC PCM corruption & truncation:** Resolved `4` valid IETF `subset` canonical MD5 mismatches (`56/60 -> 64/64` IETF `subset` MD5 match) and `1` silent 24-bit / 48 kHz PCM decoding error found in a real library track (`260/261 -> 261/261` library MD5 match).
- **ID3v2-prefixed FLAC & non-standard bit depths (`CRITICAL #2`):** Enabled ID3v2.x prefix skipping (synchsafe sizes, optional footer, stacked tags, bounded padding) with intact tag reading (`5/5` complete ID3v2 FLACs match MD5) and full-scale decoding of `8`, `12`, `15`, `20`, and `32-bit` FLACs plus Rice escape code `0` (eliminating silent `-160 dBFS` output).
- **Playback, scan & Inspector resilience:** Unreadable or unsupported FLACs now report managed errors cleanly in playback (`PlaybackFailed` / UI message), skip and log during `LibraryScanner` runs (`ScanProgress.Failed`), and display error text in Inspector without terminating the process.
- **Low sample-rate false accusations (`FORENSIC #4`):** Added a dedicated `< 44.1 kHz` Nyquist-relative branch (`92%` full-band / `85%` lossy ratios) and replaced hardcoded `"44.1 kHz"` text with the actual sample rate in both Indonesian and English (`ietf/subset/19, 20` false-fakes eliminated; `0` false-fakes on all genuine low-SR tracks).
- **False `HybridMaster` on genuine 24/96 (`FORENSIC #5`):** Required a real CD-boundary notch (`p20k - p22.5k >= 12 dB` with steep slope or CD cliff) plus ultrasonic rebound above `35 kHz` (`>= 6 dB` above `p22.5k`), evaluated ahead of `UpscaledFromCd`. Eliminated false `HybridMaster` on `ietf/subset/28–32, 37` and genuine 24/96 tracks while preserving synthetic and real hybrid masters.
- **Clean 44.1 kHz `soxr` downsamples & short clips (`FORENSIC #7.2`, `#7.3`):** Narrowed the 44.1 kHz steep-drop `Inconclusive` guard to `<= 21,250 Hz` so standard `~21.4 kHz` anti-aliasing transitions classify as `VerifiedLossless`; spread `< 10 s` short-clip FFT across 8 segments (halving `< 10 s` DEV window-perturbation flip rate from `5.1%` to `2.6%`) with an apples-to-apples `-48 dB` P90 multi-segment consistency guard.
- **MP3-in-FLAC detection on DEV & 48 kHz linear mirrors (`FORENSIC #3`, `#7.1`):** Prioritized lossy brickwall detection ahead of `UpscaledFromCd`, added container-aware 16-bit quantization floors (`<= -132 dBFS`, `σ <= 2.2 dB`) in `ComputeDeadZeroLossyBrickwall`, replaced single-bin knee lookups with 5-bin local linear-power averaging (raising DEV MP3 catches from `17/33` to `28/33` with `0` false-fakes), and extended `isFlatBroadbandMirror` to `48 kHz`.
- **Single source of truth for source audio format, ALAC bit depth, file bitrate & number formatting (`Audio/AudioSourceFormatResolver.cs`):** Fixed false `16-bit` (and `48.0 kHz` cap on 96/192 kHz) readings on 24-bit ALAC files caused by TagLib# reporting `BitsPerSample = 0` and 16-bit `AudioSampleEntry.samplerate`; now parses `ALACSpecificConfig` (`alac`) and MPEG-4 `esds` (`AudioSpecificConfig`) directly via seek-based MP4 box walking, uses FLAC `STREAMINFO` and DSF `fmt ` headers directly, removes `< 44.1 kHz` / mono clamping in `AudioMetadataReader`, reports actual average file bitrate (`file size / duration`) consistently across Library, Info Sheet, Inspector, and Signal Chain Source (while explicitly labeling uncompressed PCM output rate as `PCM 2,304 kbps` in Signal Chain Decompression), unifies SQLite and model `IsHiRes` rules (lossless only, `> 48 kHz` or `> 16-bit` or DSD), and standardizes invariant number formatting (`48.0 kHz`, `2,004 kbps`) across all UI surfaces.
- **Crash on clicking inline text (`UI/Helpers/TreeNavigationHelper.cs`):** Replaced all 22 `VisualTreeHelper.GetParent` call sites with a shared parent-traversal helper handling `ContentElement` (`Run`, `Hyperlink`, `Inline`) via `ContentOperations.GetParent` / `LogicalTreeHelper.GetParent`, eliminating `InvalidOperationException` crashes when clicking text in Inspector explanations, Settings, Info Sheet, or Lyrics.
- **Inspector track synchronization (`UI/ViewModels/InspectorViewModel.cs`, `Audio/Controller/IPlaybackTrackSource.cs`):** Bound `InspectorViewModel` to the active playback track source with generation-guarded async cancellation so changing tracks from any view updates the Inspector immediately and discards stale analysis results.
- **Real-time audio render stability, isolated forensic worker & crash silencing (`ForensicAnalysisCoordinator.cs`, `GaplessStreamQueue.cs`, `SafeFlacWaveStream.cs`, `WasapiExclusivePlayer.cs`, `App.xaml.cs`):** Serialized forensic analyses onto a dedicated `BelowNormal` worker thread (`<= 1` concurrent analysis), pooled FFT/PCM buffers (`-97.0%` per-call allocation, `0` Gen2 GC during spam), removed hidden background analysis on track switches, made playback seek/position reads non-blocking with zero-allocation in-place fades, elevated the WASAPI render thread (`ThreadPriority.Highest` + MMCSS `"Pro Audio"`), and wired `EmergencyAudioSilencer` into unhandled exception and process-exit hooks to silence active output before crash teardown.
- **Maximized bottom gap, floating-dock bleed & Clear Library UI state (`UI/Tokens/NeutralTokens.xaml`, `MainWindow.xaml`, `MainWindow.xaml.cs`, `DwmBackdropHelper.cs`, `SettingsViewModel.cs`, `MainViewModel.cs`):** Replaced the `taskbarTriggerGapPx` height inset and `ptMaxTrackSize` clamp with `SetProp(hwnd, "NonRudeHWND", 1)` + exact `rcWork` bounds and `DWMWA_COLOR_NONE` border when maximized so both Maximized and manually resized Normal windows fill 100% of the screen height with `0 px` bottom wallpaper gap while keeping auto-hide taskbar access; added a pure-neutral backdrop fade mask (`Brush.Overlay.DockBottomMask`) behind `FloatingDockCapsule`, passed `MainWindow` as owner to the Clear Library dialog, and synced cleared Album/Artist/Playlist detail views.
- **Deleted/excluded files persisting after library rescan (`Database/DatabaseManager.cs`, `Scanner/LibraryScanner.cs`, `Scanner/ScanProgress.cs`, `SettingsViewModel.cs`):** `LibraryScanner` now prunes tracks whose physical files were removed or excluded during rescan (with directory-prefix isolation and removable-drive readiness checks), cascades playlist/artist/history rows, synchronizes playlist track counts, invalidates cached extended metadata, and reports removed counts in Settings scan status.

## [2.0.1] - 2026-11-20

### Added
- **Dead-zero lossy brickwall scanner (`ComputeDeadZeroLossyBrickwall`):** Detects MP3-to-FLAC transcodes (`15.0 - 19.5 kHz` sharp drop into `-152 dBFS` digital silence) even on soft acoustic material (such as solo piano) whose harmonics fall below `-48 dB` before `16 kHz`.
- **Dead ultrasonic silence & broadband mirror guards:** Added `isDeadUltrasonicSilence` (`<= -152 dBFS` floor above `22.5 kHz` on `>= 48 kHz` containers) to block quiet CD upsamples from passing as natural acoustic roll-off, and `isFlatBroadbandMirror` (`r >= 0.30`, attenuation `<= 3.0 dB`, upper band `> -85 dBFS`, knee near Nyquist) to route broadband non-ideal resampler mirrors to `Inconclusive`.
- **Forensic regression & benchmark test suite (`tests/AuraAudio.Tests/ForensicHardeningTests.cs`):** Added 7 deterministic regression tests plus an opt-in 8-file SoniqTools CC0 real-audio benchmark (`AURA_SONIQTOOLS_DIR`), raising total suite coverage to 83 tests (`81 Passed, 0 Failed, 2 Skipped` with benchmark enabled; `80 Passed, 0 Failed, 3 Skipped` in default offline mode).

### Changed
- **Forensic engine calibration & band-averaged lookups (`Audio/Authenticity/NyquistSpectrumAnalyzer.cs`):** Replaced all remaining single-bin FFT lookups (`16k`, `20k`, `35k`, `40k`, and lossy path) with linear-power band averages (`GetBandPowerDb`), extracted magic numbers into named calibration constants, documented the `-6.02 dB` Hann coherent-gain internal scale offset, tightened `hasSmoothHiResContinuation`, widened the CD cliff window to `21.0 - 22.7 kHz`, and expanded `Detect24In32Alignment` probing from `100` frames to `4,096` frames with sign-extension verification on active frames.
- **Evidence-based verdict phrasing & universal AAC/Opus caveat (`NyquistSpectrumAnalyzer.cs`, `Core/Models/AudioIntegrityReport.cs`):** Reframed Indonesian and English verdict messages to evidence-based language, added the moderate-evidence hedge (`drop < 10 dB`) on `UpscaledFromCd`, and attached the high-bitrate AAC/Opus spectral limitation caveat across all `VerifiedLossless`, `AcousticNaturalRollOff`, and `HybridMaster` branches (`44.1 kHz`, `48 kHz`, and Hi-Res).
- **Documentation synchronization (`docs/METODE_ANALISIS_KEASLIAN_AUDIO.md`):** Rewrote the forensic methodology reference to match `v2.0.1` code (per-channel FFT power averaging, P90 multi-segment envelope, named constants, updated 44.1k/48k/Hi-Res decision tables, honest DSD synthetic curve disclosure, removal of an old local drive path, and the 8/8 SoniqTools CC0 benchmark table).
- **Version metadata:** Updated application version metadata to `2.0.1` across `AuraAudio.csproj`, `MainWindow`, `MiniPlayerWindow`, `SettingsView`, `SettingsViewModel`, `RuntimePixelPurityTests`, and `tests/ui/smoke_ui.ps1`.

### Fixed
- **Native AIFF decoding (`Audio/AudioDecoderFactory.cs`):** Switched `.aiff`/`.aif` files to `NAudio.Wave.AiffFileReader` (retaining `MediaFoundationReader` only as fallback for compressed AIFC), fixing playback and forensic analysis failures on uncompressed AIFF files.
- **Quiet acoustic 16-bit / 44.1 kHz false `Inconclusive`:** Updated `isSmoothAcousticRollOff` harmonic reach to `Math.Max(upperEnvelopeReachHz, detectedKneeHz) >= 9,000 Hz`, correctly classifying genuine soft acoustic 16/44.1 masters as `AcousticNaturalRollOff`.
- **Non-seekable stream timestamps:** `FindLoudestSectionTime` and `Analyze` now track seek failures explicitly and report `00:00` (`0.0%`) with a transparent note instead of a misleading timestamp.

## [2.0.0] - 2026-11-20

### Added
- **Pure-Monochrome Token System:** Centralized `UI/Tokens/NeutralTokens.xaml` (`R = G = B` across all 30 color tokens), app-scope `SystemOverrides.xaml`, `Metrics.xaml`, `Typography.xaml`, `Motion.xaml`, and pure-monochrome `Controls.xaml` templates with WCAG 2.1 contrast (`>= 4.5:1` text, `>= 3.0:1` interactive controls).
- **New Multi-Surface Shell:** 48px Top Bar with navigation history and search hints popup, collapsible Left Rail (`248px <-> 56px`) with virtualized drag-target playlists, Floating Bottom Dock capsule (`72px`), and responsive `360px` dual-purpose Right Split Pane (inline `>= 1440 DIPs`, overlay `< 1440 DIPs`).
- **New Library & Playback Views:** `HomeView` (4 real local SQLite shelves), `SongsView` (virtualized `DataGrid` + 3-column `ColumnBrowser`), `AlbumsView` (`VirtualizingUniformGrid`), `ArtistsView` (master-detail split), `ArtistDetailView`, `PlaylistsOverviewView`, `PlaylistDetailView`, `SearchView` (5 scopes + local browse cards), `FullScreenPlayerView` (Centered `<->` Split Lyrics), and standalone `MiniPlayerWindow` (Compact `<->` Album View + Queue/Lyrics tray).
- **Synchronized Lyrics & Import:** `LyricsParser` supporting `.lrc` sidecars, embedded LRC timestamps, ID3v2 `SYLT` frames, plain-text fallback, click-to-seek, auto-scroll pause, 3-dot instrumental gap indicators, and in-app `.lrc` import.
- **Persistent Play History:** Additive SQLite `play_history` table (capped at 500 entries) with foreign-key enforcement (`ForeignKeys = true`), powering Home *Jump Back In* and Queue *History* (with reset).
- **Unified Settings & Forensic Workstation:** Breadcrumb-driven `SettingsView` (*General*, *Playback & DAC*, *Library & Files*, *Accessibility*, *About*), full-page `InspectorView`, tabbed `InfoInspectorSheet` (`Ctrl+I`), `SignalPathFlyout`, and pure-monochrome `SpekSpectrumControl`.
- **Fluid Motion System:** Shared-progress critically damped `SpringAnimator` transitions (`damping = 1.0`, zero per-frame allocations) and Reduced Motion fallback.
- **Automated Verification Suite:** 73 active unit/STA tests (including `MotionContinuityInvariantTests`, `RuntimePixelPurityTests`, and `VolumeControlTests`) plus `tests/ui/smoke_ui.ps1` using language-independent `AutomationId`s.

- Updated application version metadata to `2.0.0` (`AuraAudio.csproj`, window titles, and `Settings > About`).
- Replaced the legacy amber application icon (`Assets/AuraAudio.ico`, `Assets/AuraAudio.png`) with a pure-monochrome multi-resolution spectrum glyph.

### Fixed

- Fixed motion continuity jumps/gaps during Right Split Pane, Left Rail, Full-Screen split morph, modal sheet close, Mini-Player resize, and `ShelfCarousel` paging transitions.
